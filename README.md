# watch

![Codex Skill](https://img.shields.io/badge/Codex-Skill-111827?style=for-the-badge)
![Video](https://img.shields.io/badge/Video-Watch%20And%20Analyze-ef4444?style=for-the-badge)

让 Codex 能“看视频”的 skill。它会下载视频、抽取关键帧、读取字幕，并在需要时调用语音转写，让 Codex 能回答视频里发生了什么。

## What It Does

- 支持视频 URL 或本地视频文件
- 自动抽帧、提取字幕，并整理成可分析材料
- 适合视频内容复盘、镜头分析、教程总结和素材审查

## Install

复制下面这段到任意电脑的 Codex 中安装：

```text
请用 $skill-installer 安装这个 skill：
https://github.com/zhangjyaa-ctr/codex-skill-watch/tree/main/skills/watch
```

安装后通常下一轮对话即可使用。
